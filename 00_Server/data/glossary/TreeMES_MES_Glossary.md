# TreeMES MES Bilingual Glossary

This is the editable default terminology file used by the subtitle application.

## Editing Rules

1. Add or update terms directly in the tables below. The application reads the `中文术语` and `推荐英文` columns automatically.
2. Use the English wording already used in TreeMES product brochures and operation guides whenever it exists.
3. Keep one primary translation for each Chinese term. Put acceptable abbreviations in `Alias`.
4. Do not change the table headers. Restart the application after editing this file so new tasks load the latest version.
