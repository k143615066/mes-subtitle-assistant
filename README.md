# MES字幕助手

面向 TreeMES 营销视频的本地字幕处理工具。上传已经人工听写完成的中文 SRT 字幕后，软件会依次进行中文优化、人工校对、目标语言翻译和目标语言可读性优化，并交付三份字幕文件。

## 同事使用：最简单的方式

1. 将本项目地址发给 Codex：<https://github.com/k143615066/mes-subtitle-assistant>
2. 向 Codex 发送以下指令：

   ```text
   请将这个公开 GitHub 项目克隆到我的电脑，完成首次启动所需的本机环境配置，然后启动“MES字幕助手”。首次需要我输入 DeepSeek API Key 时请提示我输入；不要把 API Key 上传到 GitHub 或写入代码文件。
   ```

3. 项目拉取完成后：
   - Windows：双击根目录的 `启动MES字幕助手.bat`。
   - macOS：双击根目录的 `启动MES字幕助手.command`。
4. 第一次启动时，启动器会提示输入自己的 DeepSeek API Key。输入完成后会自动创建仅保存在本机的 `.env` 配置文件。
5. 浏览器会打开 <http://127.0.0.1:15000>，开始处理字幕。

首次启动会自动创建 Python 虚拟环境并安装运行依赖，耗时取决于网络状况。电脑必须已安装 Python 3.10 或更高版本；如果启动器提示找不到 Python，将该提示原样发给 Codex，由 Codex 协助安装后重新双击启动器即可。

> 不需要 GitHub 账号即可下载、克隆和使用本项目。只有需要直接向 GitHub 提交代码或术语库修改的人才需要 GitHub 账号。

## 软件流程

1. 上传中文 `.srt` 字幕文件。
2. AI 优化中文字幕，修正明显听写错误、术语和病句，并清理不承载信息的口头填充词。
3. 人工校对并确认中文字幕。
4. 选择一种目标语言并由 AI 翻译。
5. AI 将目标语言碎片重组为更易阅读的字幕单元。
6. 下载交付文件。

## 交付文件

每个任务只选择一种目标语言，并交付以下三份字幕：

| 文件 | 用途 |
| --- | --- |
| `中文_<文件名>.srt` | 已优化并人工校对后的中文字幕 |
| `目标语言_<文件名>.srt` | 与中文字幕逐条对齐，适合核对 |
| `目标语言_可读优化版_<文件名>.srt` | 推荐交付版；将目标语言碎片合并为可读的完整句子 |

当前可选目标语言：英文、台湾繁体中文、越南语、阿拉伯语（现代标准阿拉伯语）、西班牙语（墨西哥）。

## API Key 与数据安全

- DeepSeek API Key 只保存在使用者电脑根目录的 `.env` 文件中。
- `.env`、上传字幕、生成字幕、日志和本地 Python 环境均已被 `.gitignore` 排除，不会提交到 GitHub。
- 字幕文件保留在本机；字幕文本会发送至 DeepSeek，用于中文优化、目标语言翻译和目标语言可读性优化。
- 本仓库是公开仓库，源代码与内置 MES 术语库任何人都可以查看。请不要将客户资料、未获批准的内部材料或 API Key 添加到仓库。

## 内置 MES 术语库

软件内置约 130 条 TreeMES 术语，文件为：[TreeMES_MES_Glossary.md](00_Server/data/glossary/TreeMES_MES_Glossary.md)。

可在软件顶部进入“MES术语库”页面，直接搜索、新增、编辑或删除术语。修改会写入项目本地的术语库文件，并用于后续的中文优化、目标语言翻译和目标语言可读性优化。

术语库仍以“中文术语 -> 推荐英文”为唯一人工维护标准。越南语、阿拉伯语和西班牙语（墨西哥）会参考标准英文术语生成；台湾繁体中文会参考中文和英文术语做台湾本地化。其他语言不建立单独的人工校对术语库。

术语修改只影响当前电脑。若需要同步给所有同事，请由项目维护者检查该文件的修改内容后提交到 GitHub；其他同事在 Codex 中拉取最新项目即可得到更新后的术语库。

## 功能范围

同事发布版只保留日常字幕交付所需功能：中文 SRT 上传、AI 中文优化、人工校对、目标语言选择、目标语言翻译、目标语言可读性优化、三份字幕下载与 MES 术语库编辑。

语音/视频转字幕、模型下载、历史记录、反馈、校正语料库、手动字幕拆分、时间轴合并和调试功能均不包含在本发布版中。

## 多语言说明

- 英文继续作为默认目标语言。
- 台湾繁体中文使用台湾常用词汇、繁体字和台湾标点，不是简单的简繁转换。
- 阿拉伯语使用现代标准阿拉伯语。最终导入剪辑软件时，需要确认该软件支持从右到左排版和合适的阿拉伯语字体。
- 西班牙语本期按墨西哥西班牙语生成，不使用“墨西哥语”这个语言名称。
- 中文优化和校对仍然是所有目标语言共用的前置步骤；营销人员只需要校对中文，不需要逐条校对所有外语字幕。
